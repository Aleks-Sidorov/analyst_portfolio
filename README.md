# Портфолио аналитика данных

Практические проекты по исследовательскому анализу данных, продуктовым метрикам и A/B-тестированию.

## Навыки и инструменты

**Языки и библиотеки:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn  
**Аналитика:** исследовательский анализ данных, продуктовые метрики, воронки, когортный анализ, Retention  
**Статистика:** проверка статистических гипотез, A/B-тестирование, t-тест  
**SQL:** SELECT, JOIN, GROUP BY, подзапросы, CTE
