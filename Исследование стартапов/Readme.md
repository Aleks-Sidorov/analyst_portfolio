# Исследование стартапов

## О проекте

Исследовательский проект по анализу рынка стартапов и венчурного финансирования.

В рамках проекта изучены структура и динамика финансирования стартапов, популярность различных типов финансирования, распределение объёмов инвестиций между сегментами рынка и возврат привлечённых средств.

**Цель исследования**: Исследовать динамику и структуру финансирования стартапов, чтобы выявить закономерности венчурного рынка и оценить устойчивость возврата средств. На основе этих данных сформировать инвестиционные рекомендации по покупке и развитию перспективных компаний в условиях 2015 года.

---

## Задачи

- Проанализировать компании в зависимости от сроков финансирования;
- Классифицировать сегменты рынка на массовые, средние и нишевые;
- Исследовать распределение и аномальные значения объёмов финансирования;
- Сравнить популярность и объёмы разных типов финансирования.
- Проанализировать динамику инвестиционных раундов и объёмов финансирования по годам;
- Рассчитать долю возврата средств для разных типов финансирования;
- Сформировать рекомендации по направлениям инвестирования.
---

## Данные

В исследовании использованы два набора данных:

| Датасет              | Описание                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| `cb_investments.csv` | Данные о стартапах, их финансировании, инвестиционных раундах, отраслях, статусе и датах финансирования |
| `cb_returns.csv`     | Данные о возврате средств по типам финансирования и годам                                               |


Основной датасет содержит информацию более чем о 54 тыс. записей и 40 признаках.

## Ключевые результаты

В ходе исследования:

* определены основные типы финансирования стартапов;
* выявлены различия в объёмах привлечённого финансирования;
* исследована динамика инвестиционной активности;
* выделены наиболее массовые сегменты рынка;
* проанализирована доля возврата средств для различных типов финансирования;
* сформированы рекомендации с учётом объёма инвестиций, динамики рынка и возврата средств.

## Вывод

Проект позволил исследовать основные характеристики рынка стартапов, особенности различных типов финансирования и динамику инвестиционной активности.

Полученные результаты использованы для сравнительной оценки направлений финансирования и формирования рекомендаций по инвестиционной стратегии на 2015 год.
